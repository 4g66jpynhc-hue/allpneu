Connexion Gmail

Pour envoyer le PDF par email, vous devez autoriser AllPneu à utiliser votre compte Gmail. Cette autorisation est sécurisée via Google OAuth.
Comment obtenir votre Client ID Google ?
  1. Allez sur console.cloud.google.com
  2. Créez un projet → APIs → Gmail API → Activer
  3. Identifiants → Créer des identifiants → ID client OAuth
  4. Type : Application Web → Ajoutez l'URL de ce fichier en URI autorisé
  5. Copiez le Client ID ci-dessous
